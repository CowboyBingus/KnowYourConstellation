Know Your Constellation v3.15

Supports Helldivers 2 Steam build 25327279 / game 1.8.45850.0.
Requires Bingus Shared Loader v16 or newer / API 1.

1. Close Helldivers 2 and use one mod manager.
2. Replace the previous package with Know-Your-Constellation-v3.15.zip.
3. Enable this package and Bingus Shared Loader.
4. With Arsenal's default priority, put the loader last (at the bottom).
   With first-mod priority enabled, put the loader first.
5. Purge / Deploy, then start the game normally.

Enable either the scrolling layout or Rows, not both.

To remove or change options, close the game, disable the package, and
Purge / Deploy again. Keep the loader enabled while other mods need it.

Logs: %LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs
