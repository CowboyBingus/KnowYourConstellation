Know Your Constellation - v3.16.1

Reveals mission constellations and enemy forecasts on the war table and
briefing screen so you can choose your loadout before deployment.

Release for Steam build 25480438 / EXE 1.8.46015.0. Offline checks passed; the
mod loads in live play and runs its forecast on the galactic map. The layout
was last confirmed on screen with v3.12.
v3.16.1 changes only this documentation; the mod is identical to v3.16.

INSTALL
1. Close Helldivers 2.
2. Import Know-Your-Constellation-v3.16.1.zip and Bingus-Shared-Loader-v18.zip
   into Arsenal or HD2MM, then enable both.
3. With Arsenal's default priority, put the shared loader last, then
   Purge / Deploy.
Disable the previous Enemy Intelligence package if it remains listed. The
stable manager GUID and internal module name preserve one-copy startup.

Only players with the mod see the forecast. It does not change spawns,
difficulty, gameplay rules or network traffic.
Forecasts are shown on hosted and joinable mission previews and briefing.
They are hidden on loadout and when the corresponding preview is closed.
Spawns are not guaranteed. Unavailable mission data is withheld.

Supported game build: Steam build 25480438, executable 1.8.46015.0.
The runtime checks the game and executable hashes and stops on a mismatch.
Game updates require revalidation.

Uninstall: disable this mod, then Purge / Deploy.

Requires Bingus Shared Loader v18: https://github.com/CowboyBingus/BingusSharedLoader/releases/latest
Log: %LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/EnemyIntelligence.log
