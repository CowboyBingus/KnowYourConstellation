# Know Your Constellation

Know Your Constellation now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Know Your Constellation's C source is in
[`src/components/know_your_constellation`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/know_your_constellation).

The standalone Lua mod (v4.1.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/KnowYourConstellation/tree/legacy) branch. Its releases and tags are unchanged.
